# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue.

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability** and describe what you found and how to reproduce it.

We aim to reply within 7 days. We will tell you when it is fixed and credit you if you want that.

## What counts

These are open-source learning guides and a website for each. In scope:

- Leaked secrets or credentials in a repository.
- Problems in the website code or its GitHub Actions workflows, such as script injection.
- Code samples that teach an unsafe practice without saying so.

Wrong or outdated advice is not a security issue. Open a normal issue for that.
